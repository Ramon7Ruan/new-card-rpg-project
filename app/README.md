# new-card-rpg-project

一个基于扑克牌型与筹码倍率的单人 Roguelike 卡牌游戏。纯前端，无后端、无登录、无联网。

## 运行

```bash
cd app
npm install
npm run dev      # http://localhost:5173
npm test         # 219 项测试
npm run build    # 类型检查 + 生产构建
```

## 已实现

- 牌型识别：高牌 / 对子 / 两对 / 三条 / 顺子 / 同花 / 葫芦 / 四条 / 同花顺，A 可作 1 或 14
- 计分管线：`筹码 × 倍率`，输出可回放的 `ScoreTrace`，界面按 trace 逐步动画
- 出牌 / 弃牌（每回合 4 次出牌、3 次弃牌，手牌 8 张）
- 小丑牌 18 张，5 个槽位，覆盖 6 类机制
- **消耗品 2 槽 + 12 张「铭文」**：使用后对应牌型永久 +1 级，用后出槽；牌型等级按 `base + gain × (level-1)` 生效
- **商店**：2 个商品位（小丑 / 铭文混排，单店最多 1 个铭文位）+ 重摇（$5 起，每次 +$1）
- **卖出**：小丑与铭文**仅限商店页**卖出，售价 = 原价一半（最低 $1），卖出即腾出槽位
- 盲注：2 个底注 ×（小盲 / 大盲 / Boss），目标 300·450·600 → 800·1200·1600
- **Boss 盲注 6 个**：铁壁（目标 ×1.5）/ 干涸（不能弃牌）/ 束带（手牌 -1）/ 铁律（必须出满 5 张）/ 失色（随机花色不计分）/ 无名（JQK 不计分）
- Boss 规则用声明式 `BlindRule` 表表达，按 `(seed, 底注)` 确定性抽取；被压制的牌标红斜线但仍参与牌型识别
- 手牌按点数升序自动排列（A 最大），同点数按黑桃→红桃→梅花→方块
- 选牌即算分：实时显示牌型、筹码×倍率与预计得分，并标出会计分的牌
- 经济：起始 $4，奖励 $3/$4/$5，剩余出牌 +$1/次，利息每 $5 得 $1（上限 $5）
- **卡牌增强 6 种**（附加 +30 筹码 / 倍率 +4 倍率 / 裂隙 ×2 倍率但计分后碎裂 / 铸铁留手 ×1.5 / 鎏金留手 +$3 / 幻形视为任意花色）+ **蜡封 2 种**（朱砂重触发 / 金砂 +$3）
- **符咒 18 张**（塔罗位）：对整副牌里的任意一张改花色、改点数、加增强、加蜡封，以及焚毁 / 复制 / 换钱
- **牌堆面板**：随时查看全部牌与增强、蜡封标记；符咒选目标也在这里
- **牌型等级面板**：12 种牌型各自的等级、基础 筹码 × 倍率、下一级增量
- 确定性 RNG（多种子流）+ localStorage 存档（`version: 4`，带迁移），刷新续玩

## 结构

```
src/core/    纯逻辑，零 React 依赖，可被 Vitest 直接调用
src/ui/      渲染与交互
src/test/    牌型 / 计分黄金用例 / 增强与蜡封 / 符咒 / 状态机 / Boss / 消耗品 / 卖出 / E2E / 渲染冒烟
```

架构约定：**逻辑先算完产出 trace，动画只按 trace 回放**。动画层不做任何计算。
