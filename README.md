# new-card-rpg-project

单人 Roguelike 扑克卡牌游戏。玩法源自扑克牌型 + 筹码×倍率的目标分数闯关，纯前端、无后端、无联网、可离线运行。

**在线试玩**：https://ramon7ruan.github.io/new-card-rpg-project/

push 到 `main` 后由 GitHub Actions 自动构建发布（见 `.github/workflows/deploy.yml`），测试不通过则不部署。

## 快速开始

```bash
cd app
npm install
npm run dev      # http://localhost:5173
npm test         # 295 项测试
npm run build    # 类型检查 + 生产构建
```

## 当前进度

**M0（核心可玩）已完成**：牌型识别、计分管线（ScoreTrace 可回放）、出牌/弃牌、18 张小丑、商店骨架、2 个底注共 6 个盲注、经济与存档；手牌自动排序、选牌即时算分。

**P0（Boss 盲注）已完成**：6 个 Boss 用声明式规则表实现（铁壁 / 干涸 / 束带 / 铁律 / 失色 / 无名），按 `(seed, 底注)` 确定性抽取；被压制的牌在选牌预览时标红斜线，但仍参与牌型识别；存档带版本号与迁移。

**P1（消耗品 + 牌型等级 + 卖出）已完成**：2 槽消耗品骨架、12 张「铭文」（升某个牌型 1 级，永久生效）、牌型等级增量表、商店混位（单店最多 1 个铭文位）、小丑与铭文**仅限商店页卖出**（半价，最低 $1）；存档 `version: 3` 带迁移。

**P2（卡牌增强 + 符咒）已完成**：`Card` 多出 `enhancement` / `seal` 两个字段（6 种增强 + 2 种蜡封），计分管线按「牌面筹码 → 增强 → 蜡封」逐张结算，铸铁留手加成、朱砂重触发、金砂与鎏金给钱；18 张「符咒」可对**整副牌**里的任意一张改花色、改点数、加增强、加蜡封、焚毁、复制；牌堆面板随时查看 52 张牌与增强标记；顶栏与商店都有「牌型等级」面板。

**P3（商店生态）已完成**：商店改成**两个独立池**——小丑固定 3 张、星球与符咒固定 2 张，另加 1 张优惠券与 2 个补充包；6 张优惠券永久生效并进存档（槽位 +1、货位 +1、重摇降价、利息上限 +1）；4 类补充包开 3 选 1（槽位满时禁止购买）；跳过盲注可换 1 个标签（+$6 / 随机牌型 +1 级 / 重摇免费 / 随机牌 +附加）。存档 `version: 5`。测试 295 项。

下一步按 `08_总体开发计划.md` 进 P4（内容扩量 + 平衡：小丑 18 → 50、目标曲线重调）。剩余约 122h。

## 架构约定

**逻辑先算完产出 trace，动画只按 trace 回放。** 计分核心为纯函数，不依赖 React，可被 Vitest 直接调用——这是全部重构的护栏。
