# new-card-rpg-project

单人 Roguelike 扑克卡牌游戏。玩法源自扑克牌型 + 筹码×倍率的目标分数闯关，纯前端、无后端、无联网、可离线运行。

## 目录

| 路径 | 内容 |
|---|---|
| `app/` | 游戏本体（Vite + React 19 + TypeScript strict + Vitest） |
| `00_调研与准备清单.md` | 原作机制拆解、技术选型、内容体量 |
| `01_工作量与协作方式.md` | 工时拆解、阶段划分、子代理适用范围 |
| `02_发布与版权边界.md` | 玩法/文案/商标的边界与规避清单 |
| `03_M0_需求对齐.md` | M0 需求补全与决策记录 |
| `04_M0_开发计划.md` | M0 范围锁定、任务分解、测试门禁 |
| `05_M1_开发计划.md` | M1 差距分析与范围（已被 06 修订） |
| `06_进度复盘与下一步.md` | 进度复盘、M1 切片规划 |
| `07_切片1_Boss盲注_PRD.md` | Boss 规则设计、分步门禁与验收记录 |

## 快速开始

```bash
cd app
npm install
npm run dev      # http://localhost:5173
npm test         # 93 项测试
npm run build    # 类型检查 + 生产构建
```

## 架构约定

**逻辑先算完产出 trace，动画只按 trace 回放。** 计分核心为纯函数，不依赖 React，可被 Vitest 直接调用——这是全部重构的护栏。
